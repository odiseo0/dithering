DITHERING 0.1.0 - WINDOWS 11 X64

USO

1. Ejecuta dithering.exe. No requiere instalación.
2. Abre, arrastra o pega una imagen PNG, JPEG/JPG o WebP estática.
3. Ajusta el efecto y guarda el resultado como PNG.

El programa no guarda ajustes, no usa el registro y no necesita archivos de datos junto al
ejecutable. Puedes ejecutarlo desde una carpeta normal, una memoria USB o una carpeta de solo
lectura. Los archivos que abras o guardes sí requieren los permisos normales de Windows.

LÍMITES CONOCIDOS

- Una imagen puede tener hasta 10.000.000 de píxeles y 16.384 píxeles por lado.
- No admite imágenes animadas.
- No conserva EXIF, comentarios ni perfiles ICC.
- Las imágenes de gama amplia pueden cambiar de color.
- El nombre, el icono y el diseño visual aún son provisionales.
